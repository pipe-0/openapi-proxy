openapi-proxy is made by the team behind [pipe0](https://pipe0.com), an API for finding and enriching data about companies and people.

We built it for ourselves. Our backend generates one OpenAPI document for everything it does, and our public docs and SDK need only part of it. Filtering it by hand left internal schemas in the public document and needed a change to the backend every time the selection changed. openapi-proxy is the tool we wanted instead, and it is open source so that anyone can run it.

## Contact

The source code is on [GitHub](https://github.com/pipe-0/openapi-proxy), where issues and pull requests are welcome.
